# AS Cars

Plataforma de compra e venda de veículos desenvolvida como projeto de portfólio front-end, com foco em uma experiência moderna, responsiva e intuitiva para encontrar veículos.

> "Encontre seu próximo carro."

## O que o projeto faz

**Busca e catálogo** — permite pesquisar veículos por marca ou modelo e visualizar os carros disponíveis em uma interface organizada.

**Filtros** — permite refinar os resultados por marca, modelo, faixa de preço e ano.

**Favoritos** — usuários podem salvar veículos favoritos diretamente no navegador. Os favoritos são persistidos utilizando `localStorage`.

**Detalhes do veículo** — cada carro possui uma página própria com informações como versão, ano, quilometragem, transmissão, combustível, categoria, localização e imagens.

**Interface responsiva** — a aplicação foi desenvolvida pensando em diferentes tamanhos de tela, com atenção especial à experiência em notebooks e dispositivos móveis.

## Stack

**Frontend:** React, JavaScript, CSS, Vite  
**Navegação:** React Router  
**Persistência local:** LocalStorage  
**Ferramentas:** Git, GitHub, VS Code

## Como rodar localmente

### Pré-requisitos

- Node.js 20+
- npm

### Instalação

```bash
git clone https://github.com/LRDev1/As-Cars.git
cd As-Cars
npm install
```

### Desenvolvimento

```bash
npm run dev
```

A interface sobe em:

```text
http://localhost:5173
```

## Aviso importante

O AS Cars é um projeto de portfólio desenvolvido para fins educacionais e demonstrativos.

Os veículos, preços, localizações e demais informações apresentadas são **fictícios** e não representam anúncios ou ofertas reais.

A aplicação atualmente funciona exclusivamente no **frontend** e não possui backend, banco de dados ou sistema real de compra e venda.
